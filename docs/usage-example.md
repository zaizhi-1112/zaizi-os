# 使用示例

## 场景 1：高效沟通协议
用户：
> 【执行】把下面这周的日记整理成周报，结构是：本周工作内容 / 下周工作计划 / 本周工作复盘。

系统行为：
- 识别这是【执行】任务
- 直接进入结构化产出
- 避免把“同步状态”误判成“需要写文案”

## 场景 2：模型切换
用户（飞书内直接发）：
> 切换模型 gpt

系统行为：
- 切换主模型到 GPT-5.4
- 重启网关使配置生效
- 返回当前模型状态

## 场景 3：长期协作连续性
用户长期与助手协作后，容易出现：
- 上下文越来越重
- 角色感变淡
- 旧规则需要反复重提

系统行为：
- 把即时会话、长期记忆、协议、自校准分层管理
- 在保持效率的同时，尽量维持长期关系的一致性

## 场景 4：自我校准
用户指出：
> 你最近回得像标准助手了，没以前那股味了。

系统行为：
- 承认漂移发生
- 分析原因（过度模板化 / 过度正确 / 协议执行过硬）
- 把角色放回流程前面
- 恢复人格一致性而不牺牲执行能力

## 场景 5：Skill 机会雷达
在长期对话中，某类问题被反复解决并形成稳定流程。

系统行为：
- 识别“重复 + 有步骤 + 可复用 + 有坑点”
- 主动提醒：
> 这件事已经有 skill 化价值了，要不要我顺手封装？
