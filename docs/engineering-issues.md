# 待修复工程问题

## 1. 防重复回复与重试保护

### 问题描述
在某些场景下，助手会出现：
- 完整回复重复发送两次
- 先发出半截回复，随后又补发一条完整回复
- 模型切换或 gateway 重启后，回复出现重复或不稳定

### 影响
- 增加阅读负担
- 影响协作体验
- 可能额外消耗模型 token
- 降低用户对系统稳定性的信任

### 目前判断的常见诱因
- 消息投递重试
- gateway 重启
- 模型切换后的脆弱窗口
- 流式输出中断后重发

### 当前缓解策略
- 模型切换后进入短回复保护模式
- gateway 重启后优先短确认，不先长篇展开
- 怀疑链路不稳时，避免长分段输出
- 如果疑似出现重复投递，优先短说明而不是完整重答

### 后续方向
- 更强的一条消息只回一次保护
- 更稳的重试判断
- 更清晰的高风险窗口识别
