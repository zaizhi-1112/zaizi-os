# Session Handoff Template

Use this at the end of a meaningful task, phase, or conversation block.

## Compact handoff

- Current state: what is done / what is not done
- Key decisions: what was decided
- Resume point: where future-you should continue
- Save-worthy items: what belongs in durable memory or project files

## Example

Current state:
- Communication protocol defined and accepted
- Two reusable skills packaged

Key decisions:
- Use five labels: 同步 / 快答 / 分析 / 执行 / 存档
- Prompt for label when intent is unclear

Resume point:
- Next improvement is GitHub-facing polish and install docs

Save-worthy items:
- Stable communication preferences
- Model switching command pattern
