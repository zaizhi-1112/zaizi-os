# Evaluation Heuristics

Use these heuristics to judge whether something should become a skill.

## Strong signals

### 1. Repeated twice or more
If the same class of problem appears again, skill potential rises fast.

### 2. Steps are now teachable
If you can explain the method in 3-7 steps, it is often skill-ready.

### 3. Pitfalls are now known
If you now know what breaks, what not to do, and what to watch out for, that is strong skill material.

### 4. Another user could benefit
If this is not only useful to the current user, the case for a skill gets stronger.

### 5. The solution would be annoying to rediscover
If future-you would hate having to reconstruct this from scratch, package it.

## Weak signals

These alone are not enough:
- the task was interesting once
- the output looked polished
- the user seemed excited
- the method is still fuzzy

## Fast scoring frame

Ask yes/no:
- repeated?
- structured?
- reusable?
- pitfall-rich?
- worth not rediscovering?

If 3 or more are yes, surface it as a skill candidate.
