# Prompt Patterns

Use short prompts so the assistant surfaces skill opportunities without sounding like a salesperson.

## Lightweight prompt

- `这件事已经有 skill 化价值了，要不要我顺手封装？`

Use when the signal is strong and the user is busy.

## Slightly stronger prompt

- `这已经不像一次性处理了，更像个可复用流程。要不要做成 skill？`

Use when the method is clearly reusable.

## Candidate-marking prompt

- `我先把这条标成 skill 候选。等你方便，我可以再封装。`

Use when the user is in the middle of something else.

## Why-line patterns

- `因为它已经重复出现，而且步骤清楚了。`
- `因为这次不只是解决问题，还沉淀出了方法。`
- `因为里面的坑点和判断条件已经值得复用。`

## Next-step offers

- `要不要我先起一个 skill 名字？`
- `要不要我直接给你做个 v1？`
- `要不要我先写成候选文件，后面再打包？`
